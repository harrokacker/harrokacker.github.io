Privacy Policy

Last updated: October 19, 2026

YT Pipeline is a private tool used by a single person (the owner) to manage the owner's own YouTube channels. It has no other users.

What data it accesses

With the owner's authorization, YT Pipeline uses the YouTube API Services to upload videos, set video metadata and thumbnails, and read channel and video statistics (such as views, watch time and revenue) for channels the owner controls.

How data is stored and used

Authorization tokens and statistics are stored only on the owner's own computer and are used only to run the tool for the owner. Data is not sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from Google Account permissions.

Third-party terms

YT Pipeline uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
